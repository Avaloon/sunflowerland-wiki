# Marketplace

<img class="item-icon" src="/icons/marketplace.png" alt="Marketplace" width="32" height="32" />

La **Marketplace** permet d’échanger des objets avec **d’autres joueurs**, en général contre des **FLOWER**
<img class="item-icon" src="/icons/flower-token.webp" alt="FLOWER" width="24" height="24" />
(pas des coins).

## Différence avec Betty

| | Betty (Marché) | Marketplace |
|---|---|---|
| Interlocuteur | PNJ | Autres joueurs |
| Monnaie | **Coins** | **FLOWER** |
| Prix | Fixes (définis par le jeu) | Variables (offres / listings) |

## Où l’ouvrir

Dans le jeu, cliquez sur l’icône **Marketplace**
<img class="item-icon" src="/icons/marketplace.png" alt="Marketplace" width="24" height="24" />
dans l’interface (HUD).
