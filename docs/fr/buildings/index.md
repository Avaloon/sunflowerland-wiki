# Bâtiments

Les bâtiments débloquent la cuisine, les animaux, le compost, la serre, etc. Cette page liste tous les bâtiments du jeu avec leurs coûts.

## Pour commencer

### Construire un bâtiment

1. Cliquez sur l’**Établi** (Workbench)
   <img class="item-icon" src="/icons/workbench.png" alt="Workbench" width="40" height="40" />
   sur votre ferme.
2. Ouvrez l’onglet **Build** pour voir la liste des bâtiments disponibles selon votre niveau.
3. Payez les **coins**
   <img class="item-icon" src="/icons/coins.webp" alt="Coins" width="24" height="24" />
   et les **ressources** demandées. Le bâtiment part dans votre inventaire / coffre.

### Placer un bâtiment

1. Cliquez sur le **marteau**
   <img class="item-icon" src="/icons/landscaping-hammer.png" alt="Mode aménagement" width="24" height="24" />
   en bas de l’écran pour entrer en **mode aménagement** (landscaping).
2. Ouvrez le **coffre**
   <img class="item-icon" src="/icons/chest.png" alt="Coffre" width="24" height="24" />
   (ou le panneau rapide) et choisissez la catégorie **bâtiments**
   <img class="item-icon" src="/icons/hammer.png" alt="Bâtiments" width="24" height="24" />.
3. Sélectionnez le bâtiment, placez-le sur un emplacement libre, puis validez avec
   <img class="item-icon" src="/icons/confirm.png" alt="Confirmer" width="24" height="24" />
   (ou annulez avec
   <img class="item-icon" src="/icons/cancel.png" alt="Annuler" width="24" height="24" />
   ).

### Déplacer un bâtiment

1. Entrez en **mode aménagement** avec le **marteau**
   <img class="item-icon" src="/icons/landscaping-hammer.png" alt="Mode aménagement" width="24" height="24" />.
2. Cliquez sur le bâtiment déjà posé, puis **glissez-le**
   <img class="item-icon" src="/icons/drag.png" alt="Déplacer" width="24" height="24" />
   vers le nouvel emplacement.
3. Validez le placement avec
   <img class="item-icon" src="/icons/confirm.png" alt="Confirmer" width="24" height="24" />.

### Améliorer (upgrade) un bâtiment

Certains bâtiments ont **plusieurs niveaux** (Hen House, Barn, Water Well, Pet House, Aging Shed) :

1. Cliquez sur le bâtiment déjà placé.
2. Ouvrez l’option **Upgrade**
   <img class="item-icon" src="/icons/landscaping-hammer.png" alt="Upgrade" width="24" height="24" />
   si elle est disponible.
3. Payez les **coins** et ressources du niveau suivant (détails dans chaque fiche ci-dessous).

::: tip
Certains bâtiments de base (Marché de Betty, Town Center…) sont déjà sur la ferme. D’autres demandent le niveau bumpkin indiqué ci-dessous, ou une île précise (ex. Desert pour la Serre).

**Habitations** (Town Center → House → Manor → Mansion) : **non craftables**. Elles sont **fournies / remplacées** quand vous changez d’île.

**Apparence (skins)** : beaucoup de bâtiments changent de look selon l’**île / biome** et parfois la **saison**. Ce n’est qu’esthétique (sauf pour les habitations, où le bâtiment lui-même change).
:::
