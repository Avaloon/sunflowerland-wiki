# Marketplace

<img class="item-icon" src="/icons/marketplace.png" alt="Marketplace" width="32" height="32" />

The **Marketplace** lets you trade items with **other players**, usually for **FLOWER**
<img class="item-icon" src="/icons/flower-token.webp" alt="FLOWER" width="24" height="24" />
(not coins).

## Difference from Betty

| | Betty (Market) | Marketplace |
|---|---|---|
| Who | NPC | Other players |
| Currency | **Coins** | **FLOWER** |
| Prices | Fixed (game-defined) | Variable (listings / offers) |

## How to open it

In-game, click the **Marketplace** icon
<img class="item-icon" src="/icons/marketplace.png" alt="Marketplace" width="24" height="24" />
in the HUD.
