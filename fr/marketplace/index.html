Marketplace ​

La Marketplace permet d’échanger des objets avec d’autres joueurs, en général contre des FLOWER (pas des coins).

Différence avec Betty ​

Betty (Marché)Marketplace
InterlocuteurPNJAutres joueurs
MonnaieCoinsFLOWER
PrixFixes (définis par le jeu)Variables (offres / listings)

Où l’ouvrir ​

Dans le jeu, cliquez sur l’icône Marketplace dans l’interface (HUD).

À compléter ​

Cette page est un point d’entrée. Détails sur les collections, frais, listings et offres à documenter depuis le code du jeu (features/marketplace).
